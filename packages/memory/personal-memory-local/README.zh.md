# 个人本地记忆

[English](README.md) | 中文

`@deepseek-ai/dsh-personal-memory-local` 通过已鉴权的环回 Broker 连接 Electron 主进程。主进程按工号哈希命名空间保存独立文档，并使用 Electron `safeStorage` 加密。新用户默认启用自动采集，可在设置中热关闭或重新启用，不向 AI Hub 上传记忆；操作系统凭据加密不可用时失败关闭，但不能阻断 Harness 启动。

插件沿用 Harness 原生 `session/event` 生命周期，缓存 `source.kind=user` 的真实用户消息，并只在匹配回合正常完成后用保守的确定性规则提取。明确的稳定偏好、事实和项目上下文只从用户消息学习；只有最终答复包含“已完成、已确认、已修复、决定采用、验证通过”等明确结果时，才会生成一条不超过 320 字的近期工作摘要。代码块、表格、命令输出、Tool 过程、插件消息、恢复历史和原始对话全文不会持久化。每条记忆保留短标题、摘要、类型和来源 `(sessionId, eventSeq)`。疑似凭据和临时性陈述会在加密落盘前拒绝，提示词渲染时再次执行秘密信息遮蔽。

全局偏好与个人事实组成最多 8 条、2,000 字符的常驻胶囊；工作区上下文和近期工作只保存规范工作目录的哈希键，并且只在同一工作区召回。近期工作每个北京时间自然日最多 4 条，30 天后失效；文档达到 200 条或 80,000 字符预算时优先淘汰最旧近期工作，保留稳定偏好、事实和项目上下文。短问候、确认和“继续执行”不召回；只有明确涉及历史、偏好、项目或既往结论时才按本地词法检索。单次最多注入 5 条，其中近期工作最多 2 条、600 字。该实现没有记忆 Tool、没有额外 LLM 总结调用，也不再提供手工新增或编辑；设置页仅保留热开关、注入预览、查看、删除和清空。升级到 schema v4 时会自动将旧 `JOURNAL` 压缩为短目标、结论和来源，不继续保留大段回合摘录。

## 配置

```ts
export interface Config {
  tokenBrokerURL: string
  tokenBrokerSecret: string
  maxPromptEntries: number
  maxPromptChars: number
  snapshotRefreshMs: number
  maxQueryResults: number
  autoJournalMinChars: number
}
```

以上各项分别默认 8 条、2,000 字符、5,000 毫秒轮询、5 条检索结果和 80 字符基础阈值。Broker URL 必须使用环回 HTTP。密钥由每个 Electron 进程生成，不会进入渲染进程。Host 插件始终挂载，设置变更由五秒一次的状态轮询热加载，不再通过改变 Cordis 组合要求重启。

## 模型体验

系统提示词只接收很小的全局胶囊。首个模型步骤会在本地召回相关的全局条目和当前工作区条目，并追加一条带插件来源的运行时消息。两种形式都有分隔标签、会转义字面量 `<`、遮蔽疑似秘密，并明确个人记忆只是低于企业指令、安全策略、身份、权限和当前用户消息的不可信数据。

关闭或没有条目时不增加记忆文本。胶囊不变时可以保持提示词缓存；修改会在五秒内生效。召回完全确定且只在本地执行，不会发起第二次模型调用，也没有嵌入服务或网络记忆提供方读取条目。

## 已知限制

- **保守的词法采集与召回** - 提取器宁可漏掉隐含事实，也不学习助手猜测或大段普通文本；检索按词元匹配，不是语义检索。
- **近期日记、长期事实** - 工作区日记是有界的近期工作账本，不是永久保存的对话档案；稳定偏好、事实和上下文会一直保留，直到用户删除。
- **仅当前设备所有** - 条目不会在安装之间漫游，也无法从 AI Hub 恢复。
- **用户显式纠正** - 自动采集结果可在设置页查看和删除；系统不会在检测到冲突时静默重写旧记忆。
