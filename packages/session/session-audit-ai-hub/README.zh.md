# AI Hub 对话审计

[English](README.md) | 中文

`@deepseek-ai/dsh-session-audit-ai-hub` 监听 Harness 的规范会话事件，在每个 turn 结束后向 AI Hub 提交一条审计记录。记录包含用户文本、最终助手文本、模型、Token 数、耗时、结束状态和稳定的客户端安装标识；明确排除思考过程、文件正文和完整 Tool 参数。

插件只通过桌面端已认证的回环 Token Broker 获取当前 WorkBuddy Access Token，Token 不进入 Cordis 配置或日志。Hub 返回 401 时会强制刷新一次，临时失败执行有限重试。上报失败不会打断当前对话，插件销毁时会等待已进入有界内存队列的记录完成。

## 模型体验

无。该观察者不注册提示词、Tool、消息或模型请求，也不修改 Session 日志。

#### KV Cache 影响

无；审计链路在规范事件产生后运行，不组装模型输入。

## 已知限制与延期工作

- **只在内存中投递** - 进程异常退出可能丢失尚未完成上传的记录。
- **尽力隔离** - Hub 持续失败只会记录日志，不阻断或回滚用户 turn。
- **内容策略由部署侧管理** - 留存、脱敏和访问审批仍属于 AI Hub 管理职责。
