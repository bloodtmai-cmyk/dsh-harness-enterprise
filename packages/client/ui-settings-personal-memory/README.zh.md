# 个人记忆设置

[English](README.md) | 中文

当 context-isolated preload 暴露窄化的个人记忆桥时，`@deepseek-ai/dsh-client-ui-settings-personal-memory` 会向系统设置贡献仅桌面端可见的**个人记忆**分区。页面包含热启停开关、自动采集条目数量、下一轮最大注入预览、稳定记忆与近期工作标签，以及删除和清空控件；不再提供手工新增或编辑表单。每条记忆展示短标题、摘要、类型、本地会话来源和更新时间。组件不会获得工号、加密密钥、AI Hub Token 或文件系统路径。

删除单条和清空全部都需要确认。UI 仅在主进程操作提交后显示成功；系统加密不可用时会给出错误，但不会提供打开原始配置文件的绕过入口。

## 模型体验

### 设置贡献

#### 模型看到的内容

无。本包只通过 IPC 呈现本地设置；自动采集和面向模型的有界召回由独立 Host 插件拥有。

#### Token 影响

无。浏览器端贡献不组装也不发送模型请求。

#### KV Cache 影响

本包自身没有影响。切换功能或删除条目后，独立 Host 插件会在轮询周期内更新其模型输入。

## 已知限制与延期工作

- **仅桌面端** - Electron preload 桥不可用时不显示该分区。
- **轮询延迟** - 启停和删除均为热生效，但 Host 最多需要五秒读取到已提交状态。
