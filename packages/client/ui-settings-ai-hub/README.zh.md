# AI Hub 企业能力市场

[English](README.md) | 中文

`@deepseek-ai/dsh-client-ui-settings-ai-hub` 在左侧边栏新增独立的“企业能力市场”入口，不再放在 Web 设置中。只有 AI Hub 实时菜单权限包含 `PLUGIN_MARKET` 时才显示入口；权限撤销后会隐藏入口，并关闭已经打开的市场。页面展示已发布的 MCP、Skill、Bundle 和客户端插件，以及当前用户的可申请、审批中、已授权或已拒绝状态。企业指令是全员策略，不进入可申请目录。

该页面通过 `ctx.remote.aiHubCatalog` 解析菜单权限、读取市场并提交申请，不会获得 AI Hub Token、安装制品或调用 MCP Gateway。Host 通过桌面回环 Broker 获取短时 Token，并代替页面调用 AI Hub。菜单权限失败关闭且每分钟刷新；加载、未接入、空目录、错误、重试、窄屏、分类筛选和行内申请状态仍由市场弹层本地管理。

Electron 所有者定时对账授权变化并负责安装制品。Skill、企业指令、MCP/Tool 可见性和通过准入的 `activation=hot` 客户端插件都在运行中生效；插件只有在受管 Patch SHA-256 完成事务提交后才确认成功，候选失败会恢复上一份健康 generation。Settings 旁的纯图标升级入口只保留给 Harness 二进制版本，即使用户没有市场菜单权限也仍可看见；点击后由同一个原生对话框选择“立即下载并重启”或“下次启动时静默升级”。

## 模型体验

无。该包只管理浏览器侧市场工作流，不注册任何模型可见内容。

#### KV Cache 影响

无；该包不会组装或发送模型请求。

## 已知限制与延期工作

- **有边界的热激活** - 任意模块目录 HMR 仍禁用，只监听 AI Hub 唯一受管 Patch 并事务重组；插件失败时回退，并在下次启动重试一次。
- **实时菜单强制执行** - 缺少 `PLUGIN_MARKET` 时边栏不显示，AI Hub 也会在市场接口再次执行同一权限检查。
- **用户只能申请** - 授权、撤销、发布和制品审批仍由 AI Hub 管理员负责。
