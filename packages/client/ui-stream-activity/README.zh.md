# @deepseek-ai/dsh-client-ui-stream-activity

[English](README.md) | 中文

面向企业桌面端实时对话过程的呈现插件。它只使用 `ui-conversation` 与 `ui-tool` 发布的稳定数据属性，把推理和 Tool 活动显示成紧凑、低干扰的流式列表。运行步骤保留克制的活动标记，已完成过程继续使用现有折叠项，展开后的输入输出卡片仍完整保留，便于追溯审计。

本插件只有 CSS 呈现，不修改助手内容、Tool 调用、审批、事件存储或审计投影。移除对应 Cordis 行即可恢复 Harness 基础样式。

## 模型体验

无。本插件只改变浏览器呈现；其中没有任何内容进入模型请求。

#### KV Cache 影响

无。本插件既不组装也不发送模型请求。

## 已知限制与暂缓事项

- **只负责呈现**——插件不会改写模型生成的推理文本或 Tool 摘要。它依赖稳定的 `data-stream-*` 约定，并有意把展开后负载的布局继续交给原组件负责。
